! Base configuration of the EVE-NG lab (Cisco IOL), as used by the team.
! IBN's kb/topology.yaml describes this network. The management network (Ethernet0/3 / Vlan99)
! is added on top of this; see README "Connecting EVE-NG".
! Note: in IBN the second switch is called SW3 (as in the diagram).

R1
--
en
conf t
hostname R1

int e0/0
ip address 10.1.2.1 255.255.255.0
no sh 
duplex full

int e0/2
ip address 10.0.1.1 255.255.255.0
no sh 
duplex full

router ospf 1
router-id 1.1.1.1
network 10.1.2.0 0.0.0.255 area 0
network 10.0.1.0 0.0.0.255 area 0

int tunnel 1
ip address 10.1.3.1 255.255.255.0
tunnel source e0/0
tunnel destination 10.2.3.3 

ip route 10.0.3.0 255.255.255.0 tunnel1 10.1.3.3



end
